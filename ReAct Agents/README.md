# 🤖 Agentic AI System Design for PMs
### Module: Building ReAct Agents with CrewAI

A hands-on Google Colab notebook for senior Product Managers to learn how ReAct agents work — by building a real multi-agent system from scratch.

---

## What You'll Build

A **Product Launch Intelligence System** for a fictional fintech startup (NovaPay) that autonomously researches markets, maps competitors, and produces a go-to-market recommendation for a European expansion — using a team of three specialized AI agents.

## Prerequisites

- A Google account (to run Colab)
- An [OpenAI API key](https://platform.openai.com) (~$0.15–0.40 in credits per run)
- Basic familiarity with Python syntax (helpful but not required)

## How to Run

1. Open the notebook in [Google Colab](https://colab.research.google.com)
2. Add your OpenAI API key via **Secrets** (🔑 icon in the left sidebar) as `OPENAI_API_KEY`
3. Run cells top to bottom with `Shift + Enter`

## What's Inside

| Part | Topic |
|------|-------|
| 1–2 | What is a ReAct Agent? Scenario & system architecture |
| 3–4 | Setup, installation, and custom tool creation |
| 5–6 | Defining agents and tasks |
| 7–8 | Running the crew and reading results |
| 9 | How the ReAct loop works under the hood |
| 10 | Experiments: modify goals, build new tools |
| 11–12 | PM design principles, discussion questions, assignment |

## Stack

- **[CrewAI](https://docs.crewai.com)** — multi-agent orchestration
- **OpenAI GPT-4o** — the underlying LLM
- **Python 3.10+**
