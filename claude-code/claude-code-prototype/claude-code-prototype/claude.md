# Project Manager Starter Kit — Claude Code Guide

## What is this project?
This is a demo workspace for product managers learning Claude Code.
The goal: show how AI-assisted development works in practice, from idea to implementation.

## Project Overview
See `docs/overview.md` for the product vision and design principles.
See `docs/prd.md` for the current Product Requirements Document.

## How Claude should behave in this project
- Keep responses concise and non-technical where possible
- Explain *why* before *how* when making decisions
- Flag tradeoffs clearly — don't just pick one approach silently
- When editing files, describe what changed and why in plain English
- Prefer simple solutions over clever ones

## Key conventions
- All product docs live in `docs/`
- Feature ideas go in `docs/prd.md` under the Backlog section
- Design decisions get recorded in `docs/overview.md`

## What PMs can ask Claude Code to do
- "Draft a PRD section for [feature]"
- "Summarize what changed in this file"
- "Review this PRD and flag gaps or missing edge cases"
- "Turn this bullet list into a user story"
- "Generate a simple prototype for [feature]"
